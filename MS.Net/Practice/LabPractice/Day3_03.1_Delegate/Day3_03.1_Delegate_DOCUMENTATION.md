# Day3_03.1_Delegate — Project Documentation

## Overview
Demonstrates delegates and events to implement a simple discount selection system where a customer can choose between summer and winter discounts.

Files:
- `Program.cs` — contains delegate, `Customer` class with events, and main flow showing event subscription.

## Run
- Build: `dotnet build`
- Run: `dotnet run --project Day3_03.1_Delegate\Day3_03.1_Delegate.csproj`

## Source (`Program.cs`)
```csharp
namespace Day3_03._1_Delegate
{
    internal class Program
    {
        static void Main(string[] args)
        {
            Customer customer = new Customer();
            customer.CustomerName = "Akshat";

            myDiscountDelegate summerDiscount = new myDiscountDelegate(SummerSale);
            myDiscountDelegate winterDiscount = new myDiscountDelegate(WinterSale);

            customer.ApplySummerDiscount += summerDiscount;
            customer.ApplyWinterDiscount += winterDiscount;

            Console.WriteLine("Hello, " + customer.CustomerName + " , please choose form this...");
            Console.WriteLine("1. Summer Sale   2. Winter Sale");

            customer.ApplyDiscount(Convert.ToInt32(Console.ReadLine()));

            Console.ReadLine();
        }

        public static void SummerSale()
        {
            Console.WriteLine("Summer Sale : 80% Discount");
        }

        public static void WinterSale()
        {
            Console.WriteLine("Winter Sale : 75% Discount");
        }
    }

    public delegate void myDiscountDelegate();

    public class Customer
    {
        private string CustName;

        public string CustomerName
        {
            get { return CustName; }
            set { CustName = value; }
        }

        public event myDiscountDelegate ApplySummerDiscount;
        public event myDiscountDelegate ApplyWinterDiscount;

        public void ApplyDiscount(int choice)
        {
            switch (choice)
            {
                case 1: 
                    ApplySummerDiscount();
                    break;

                case 2:
                    ApplyWinterDiscount();
                    break;
            }
                
        }

    }
}
```

## Layman explanation & analogy
Imagine a store where the cashier announces discounts over a loudspeaker. The store defines two announcements (summer and winter sales). The `Customer` acts as a switchboard that triggers the correct announcement when a customer chooses an option. The delegate is like a pre-written script for the announcement, and the event is the loudspeaker that broadcasts the script to listeners.

## Suggested improvements
- Use `int.TryParse` for safe input parsing.
- Use `?.Invoke()` when raising events (`ApplySummerDiscount?.Invoke()`), avoiding null reference exceptions when no listeners are attached.
- Pass contextual data (like discount percentage or product list) to handlers using delegate parameters or custom `EventArgs`.
- Consider unit tests for `ApplyDiscount` to ensure correct event is triggered for each input.
